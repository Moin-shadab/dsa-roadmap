📖 Sorting Algorithms — Plain English
AlgorithmHow a kid would explain itBest SpeedWorst Speed
Bubble Sort Compare two neighbors. If left > right, swap them. Keep doing passes until nothing swaps. Like bubbles rising to top! O(n) O(n²)
Selection Sort Find the smallest number. Put it first. Find next smallest. Put it second. Simple but slow. O(n²) O(n²)
Insertion Sort Like sorting playing cards in your hand. Pick next card, slide it left until it's in right spot. O(n) O(n²)
Merge Sort Split list in half, sort each half, then merge back together. Divide and conquer! Always same speed. O(n log n) O(n log n)
Quick Sort Pick a "pivot" number. Put smaller numbers left, bigger right. Sort each side. Usually fastest in practice! O(n log n) O(n²)

💡 Why Binary Search is Magic
With 1,000,000 numbers, linear search needs up to 1,000,000 steps.
Binary search needs at most log₂(1,000,000) ≈ 20 steps.

That's the difference between 1 second and 0.00002 seconds! 🚀

Tree Traversal Visualizer
🤔 What is a Tree? Think of your family tree! You're connected to parents, who are connected to grandparents. In computers, a "tree" organizes data in parent-child relationships. The "root" is at top (opposite of real trees!). Each node can have left/right children.
🌳 Binary Tree Traversal
Visit order:
Choose a traversal type and press ▶ Traverse!
🗺 Inorder (Left→Root→Right)
For a BST, gives nodes in sorted order!
Use: getting sorted list from BST, validate BST.
📷 Preorder (Root→Left→Right)
Visits root first. Used to copy/serialize a tree.
Think: take a photo of the tree top-down.
🗑 Postorder (Left→Right→Root)
Visits root last. Used to delete a tree safely (children first, then parent).
🏢 Level Order (BFS)
Level by level, left to right. Like reading a building floor by floor. Uses a Queue. Finds shortest path!

🔵 BFS — Breadth First
Uses a Queue (FIFO). Explores all neighbors of current node before going deeper.
Like ripples in a pond. Finds shortest path!
Use: maps, social networks distance, web crawling.
🟣 DFS — Depth First
Uses a Stack (or recursion). Dives as deep as possible before backtracking.
Like exploring a maze — go all the way then back up.
Use: cycle detection, topological sort, puzzle solving.
